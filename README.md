# FABRIC-Scripts-for-EIBP
EIBPDepsLarge.ipynb:- This script is used to install Dependencies.
FabUtils_new.py:- Contains new Utility functions for FABRIC scripts.
EIBPStartLarge.ipynb:- This Script will compile the C code and start EIBP in the nodes.
EIBPTestLarge.ipynb:- This Script contains H/w and S/w enabled failure testing.

the Config file has the intial settings/parameters to be used while executing the C code. The Access router interfaces connecting to the IP nodes have to be updated
